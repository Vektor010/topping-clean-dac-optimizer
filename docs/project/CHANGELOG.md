# Changelog

All notable changes to the TOPPING Clean DAC Optimizer project will be documented in this file.

## [1.0.0] - 2026-11-17

### Added
- **Topping_Debloat_Tweak.bat**: 1-click standalone tweak to remove the DAC tray icon, terminate the background Node.js server (`TOPPING Home.exe`), and remove autostart entries.
- **Install_Clean_Driver.bat**: 1-click installer registering certified Thesycon kernel drivers directly into the Windows `DriverStore` using native `PnPUtil`.
- **Topping_DAC_Manager.bat**: Interactive bilingual management console with hardware detection, latency testing, ASIO buffer adjuster, driver export, and rollback.
- **Restore_Default_Settings.bat**: 1-click rollback script restoring original tray icon and autostart tasks.
- **Genuine Driver & ASIO Packages**: WHQL-certified Thesycon v6.16.0 drivers and direct bit-perfect ASIO libraries.
- Complete bilingual documentation (Russian and English) with official driver links, search guides, and 2026 Windows 11 compatibility.
