# Getting Support

## Troubleshooting & Common Questions
Before submitting an issue, please check:
1. **Quick Start Guide** in [README.md](README.md) or [README_RU.md](README_RU.md).
2. **Diagnostics in Manager**: Run `Topping_DAC_Manager.bat` and select `[4]` to check live hardware status and driver binding.
3. **Official Portals**: For hardware warranty or firmware updates, visit [TOPPING Support](https://www.toppingaudio.com/support).

## Opening an Issue
- If you encounter a script error, run `tests/Test-ScriptsSyntax.ps1` and include the output.
- For unsupported device reports, provide your hardware Vendor ID and Product ID (from Device Manager or `pnputil /enum-devices /class ToppingUsbAudio_sc`).
