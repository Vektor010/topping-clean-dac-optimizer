# Product Roadmap

- [x] Standalone 1-click debloat tweak (`Topping_Debloat_Tweak.bat`).
- [x] Clean kernel driver installer via `PnPUtil` (`Install_Clean_Driver.bat`).
- [x] Bilingual interactive management console (`Topping_DAC_Manager.bat`).
